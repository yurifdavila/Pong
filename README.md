# Pong
## Sobre o Projeto
Esse projeto foi desenvolvido utilizando a primeira versão do PPlay e implementa conceitos de: 
* Game Loop
* Lógica de colisões
* Construção e segmentação de código

## O que Aprendi
Nesse projeto, obtive grande experiência ao colocar em prática e consolidar meus conhecimentos sobre a linguagem Python e em lógica de programação. Em paralelo, pude desenvolver minhas habilidades na resolução de problemas e vivenciar como é a concepção de um projeto.
