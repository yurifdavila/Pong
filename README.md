# Pong
Releitura do clássico Pong utilizando o PPlay, uma biblioteca de jogos baseada em Pygame desenvolvida na UFF.
SOBRE
Esse projeto foi desenvolvido utilizando a primeira versão do PPlay. 
E implementa conceitos de: 
*Game Loop
*Lógica de colisões
*Construção e segmentação de código
O que aprendi
Nesse projeto, obtive grande experiência ao colocar em prática e consolidar meus conhecimentos sobre a linguagem Python e em lógica de programação.
Em paralelo, pude desenvolver minhas habilidades na resolução de problemas e vivenciar como é a concepção de um projeto.
